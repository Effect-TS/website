# Effect Website

The public web application, documentation site, and interactive TypeScript editing surfaces for Effect.

## Language

**Playground**:
The full multi-file code editing and execution environment at `/play`.
_Avoid_: Editor, sandbox, scratchpad

**Scratchpad**:
The standalone single-file TypeScript editing surface at `/scratchpad` with live language intelligence and no code execution.
_Avoid_: Lite playground, mini playground, editor
