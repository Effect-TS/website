By the end of this course you will have built rulebook, a small engine that runs
on your own machine. You give it rules as JSON. It receives events over HTTP,
polls URLs on a timer, runs the actions of the rules that match, writes every
run to SQLite, and shows each step as a trace. The last action you add sends a
notification to your phone.

{/* Slot for the finished-app clip. Until the clip exists, the lesson 10 run below stands in for it. */}

Part 1 builds the core of that in one file: a rule, an event, and an alert line
when the rule matches. The editor holds the file Part 1 ends with, and it is
already running. Open the Terminal tab under the editor:

- three alert lines for the laptop expense of 1200, one for each rule in the
  store;
- three skip lines for the taxi expense, which has no amount to compare.

The Trace Viewer tab next to it shows each rule evaluation as a timed span.

Don't try to read the file yet. Every line arrives in a lesson of its own,
together with the problem it solves. If you want to poke at it, change the
laptop's `amount` from `1200` to `300` and watch the alerts change when the
terminal reruns the file.
