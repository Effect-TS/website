### Effect v4 updates.

Effect 4.1.5 went out on Friday, and the week brought new chat integrations, more protobuf and crypto building blocks, and another round of fixes across the codebase.

- **Additions**: Added `effect/chat` with `@effect/chat-slack`, `@effect/chat-discord` and `@effect/chat-whatsapp`, `effect/crypto/Password` for storing passwords as PHC strings with Argon2id or PBKDF2, `effect/workers/SharedMemory` for sharing typed arrays with workers, and a `CloudflareTracer` in `platform-cloudflare`. Protobuf gained `ProtobufDescriptor` and `ProtobufMessage` to work with messages by descriptor, without Schema, and `Xml` gained `Xml.toEvents` and strict namespace processing. Also added per-procedure RPC tracing, `staleTime` for HTTP and non-stream RPC atom queries, a tracing span around each SQL `Migrator` run, and captured `TestConsole` output for warning, info, debug and trace levels. `effect/http` now supports RFC 8288 `Link` headers (`Headers.parseLink`, `Headers.formatLink`, `Schema.LinkHeaderFromString` and `HttpClientResponse.links`), with new helpers to append headers, and a standalone `effect/ai/Skill` module can be registered with `McpServer.registerSkill` and `McpServer.skill`.

- **Behavior changes**: Zoneless `DateTime` strings such as `2024-1-15` are now parsed as UTC instead of local time. `Result.Success` is serialized under `success` instead of `value` in `toJSON` and `JSON.stringify`, and `SchemaGetter` base64, hex and URI component encoders report an invalid value when they meet an unpaired UTF-16 surrogate. Negative zero is now encoded as `"-0"` in `Schema.NumberFromString`, `Schema.FiniteFromString` and `Schema.toCodecStringTree`, and explicit `HttpRouter` routes take precedence over a wildcard at their bare prefix.

- **AI & MCP**: Typed toolkit handlers can now return native MCP content blocks, and `McpServer` sends tool model output as tool result content. Fixed `McpServer` toolkit registration growing with the square of the tool count, MCP tools marked `Tool.Readonly` being listed as destructive, `LanguageModel.streamText` dropping approved tool results when tool call resolution is disabled, and RPC and MCP stdio serving stopping after a malformed NDJSON line. Bedrock now honors tool model output and handles non-object tool results, OpenRouter gets tool result file parts as content items, and OpenAI streamed refusal explanations are preserved.

- **Cluster & workflow**: Fixed stranded shards after persistent runner lock failures, held entity keep-alive requests completing on redelivery, premature workflow finalizers on durable wakeups, and activity restart loops after durable clock wakeups with SQL storage. Workflow activity replies stay available for same-runner redelivery, and `ClusterCron` entities are annotated with their schedule.

- **HTTP, RPC & platform**: Server spans and request logs can now redact secret path params with `redactedParams`. `NodeHttpServer` returns 503 while it is not yet serving, `HttpRouter.serve` provides the app's services to the server, and inbound WebSocket buffering is bounded across runtimes with `highWaterMark`. Fixed a stalled `RpcClient` stream blocking other responses on its connection, RPC socket write failures escaping as defects, `HttpServerResponse` setters resetting an explicit `Content-Type`, and Web `File` byte ranges on Node.js. On the generator side, OpenAPI clients now include operation summaries in method comments and match multipart payload types, and `HttpApi` generation handles binary bodies, SSE responses and local Path Item references.

- **SQL & persistence**: Added an option for ClickHouse clients to skip the startup ping, widened the PostgreSQL `PersistedQueue` sequence to `bigint`, and let PostgreSQL streams time out while queued on a transaction connection. Fixed anonymous record decoding and leading U+FEFF handling in `sql-pg`, Vitess idle advisory-lock heartbeat races, and `EventJournal.makeMemory` dropping entries imported during an upload.

- **Core & Schema fixes**: The audit continued with fixes for `Queue.take` not delivering the final item before closing waiters, race losers that synchronously settle the race, forked fibers interrupted before starting sometimes running their effect instead of exiting interrupted, `Effect.tx` spinning when its body recovers from `Effect.txRetry`, `Cache` and `ScopedCache` expiry using the default clock after the first caller is interrupted, and `HashMap` and `HashSet` overflowing the stack on custom hashes that are not 32-bit integers. Also fixed `Stream` groups being dropped while values are offered, `Atom.kvs` showing a value from before the last write, `Order.Struct` ignoring symbol comparator fields, struct field discovery across APIs, `Schema.CauseReasonIso`, `DateTime.make` with a time zone followed by a comment, `Chunk.fromIterable` sharing the caller's array, and `Unicode` letter handling in `String` case helpers. Summary metrics now reject `NaN` quantiles, and the OTLP exporter warns when a failed export disables it.

You can follow the full changelog in the [effect repository](https://github.com/Effect-TS/effect/commits/main).

- [atrim.ai](https://atrim.ai/docs/connect/) - an OpenTelemetry backend that takes OTLP traces, metrics and logs with an ingest token. The Effect guide wires up `Otlp.layerProtobuf` from `@effect/opentelemetry`, so `Effect.withSpan` calls become spans and `Effect.log` becomes a log record on the same trace.

- [Pinna for Effect](https://pinna.frondruntime.dev/effect) - `@frondruntime/pinna-effect` puts synchronous domain state on Effect Schema. Models are `Schema.Class` types whose fields check every write and roll back the update on failure, with scoped helpers like `watchScoped` and `fromStream`. By romanonthego.

- [TypeSQL Effect adapter](https://typesql.karsli.net/adapters/effect) - `@typesql/effect` runs TypeSQL statements as Effects on an Effect `SqlClient`, for PostgreSQL, SQLite and MySQL/MariaDB. It has typed `SqlError` failures, `stream()` and `sql.withTransaction`. By ismailkarsli.

- [wardic](https://github.com/wardiclabs/wardic) - an animation engine with Motion's API, built on Effect. It brings `initial`, `animate`, `exit`, gestures and layout animations to SolidJS, and runs on Effect internally so you don't write any Effect code. By wardiclabs.

- [forkyard](https://github.com/SeeThruHead/forkyard) - runs several checkouts of the same repo side by side, each with its own copy of your service stack at its own `*.localhost` URL. Built with Effect. By SeeThruHead.

- [effect-linq](https://github.com/julionav/effect-linq#readme) - an EF Core-style data access library for Postgres, built on Effect SQL. By julionav.
