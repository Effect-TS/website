Each lesson since
[Using FileSystem and NodeRuntime.runMain](/learn/part-2/11-your-program-your-entrypoint)
has added layers as the program needed them. The server's layers are
composed in `src/server/main.ts`, while the CLI's are composed in its run
line. Both entrypoints work, but finding out which services each program
uses now means reading through its startup code.

Move both compositions into `src/Layers.ts`, so you can see the dependencies
in one place. This is a refactoring: the program should behave exactly as it
did before.

## Collect the layers in Layers.ts

Create `src/Layers.ts`. Move the server's stack there as an exported value
named `server`, and the CLI's stack as an exported value named `cli`:

<LessonCode file="checkpoints/23/src/Layers.ts" />

These are the same layers you built during the course. Each `Layer.provide`
supplies the dependencies of the layer above it, which also determines their
lifetime. The Engine is built after the stores and SQLite, and closes before
them. Moving this composition into a separate file preserves that order.

## Simplify the entrypoints

Replace the server's stack with the exported layer. The server entrypoint now
only launches it:

<LessonCode file="checkpoints/23/src/server/main.ts" />

In `src/cli/main.ts`, replace the CLI's stack with `Effect.provide(Layers.cli)`.
That is the CLI's only `provide`.

Leave the `Effect.provideService` calls inside the Engine where they are. They
supply individual effects with services the Engine has already acquired;
they do not build the application's dependencies.

## Check that nothing changed

Run `pnpm check` and `pnpm test`. Both should still pass.

Then repeat the run from
[Diagnosing a request from its trace](/learn/part-3/22-diagnose-it)
from an empty `reflex.db`. Your server produces the same four rows.

## Checkpoint

Checkpoint 23 runs the refactored server with the same behaviour as before:

```sh
pnpm checkpoint 23 server
```

Neither entrypoint should contain a `Layer.provide`, and each should have at
most one `Effect.provide`. The test in
`checkpoints/24/test/Layers.test.ts` checks these constraints. Copy it into
`test/` to check your own `src/`.
