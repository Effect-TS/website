The alert is hard-coded. Reflex should look at an amount, decide whether it
is large, build the message, log it, and give the message back. Those are
steps that run in order, and each one uses the result of the one before. By
the end of this lesson `program` does all of them, and the terminal still
prints `expense 1200 over 500`.

In this lesson you will:

- write steps in order with `Effect.gen`
- run an Effect inside a generator with `yield*`
- return a value from a generator and see it in the success type
- see what happens when you forget a `yield*`

Run the file. The terminal prints one log line with the message
`expense 1200 over 500`.

`Effect.gen(function* () { ... })` builds one Effect from steps written one
per line. `function*` makes the block a generator. That is all you need to
know about generators in this course.

Inside the block, `yield*` runs an Effect and hands you its result before the
next line runs. `isLarge(amount)` is called without `yield*` because it is a
plain function, not an Effect. Save `yield*` for Effects.

## 3. Read the success type

Hover `program`. The type is `Effect<string, never, never>`.

The success type changed from `void` to `string`. Whatever the generator
returns is what the whole Effect gives back, and this one returns `message`.

## Try it

Delete the `yield*` in front of `Effect.log(message)`.

1. Hover `Effect.log(message)`. It is an `Effect<void>`, a description of
   logging.
2. Run the file. The log line is gone. The description was built and then
   dropped, because nothing ran it.
3. Notice that TypeScript did not complain. A forgotten `yield*` is not a
   type error.
4. Put the `yield*` back and run the file again. The line is back.

When a log line or a step goes missing, a missing `yield*` is the first thing
to look for.

## What you learned

- `Effect.gen(function* () { ... })` builds one Effect from steps that run in
  order.
- `yield*` runs an Effect and gives you its result. What you `return` becomes
  the success type.
- Plain functions such as `isLarge` are called without `yield*`.
- An Effect you build inside a generator and do not `yield*` never runs, and
  TypeScript does not warn you.
- In [Naming steps with Effect.fn](/learn/part-1/07-name-it-see-it) you give a
  generator a name, so its failures say where they came from.
