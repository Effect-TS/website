The `effect/unstable/process/ChildProcess` module provides a way to create and run commands with the specified process name and an optional list of arguments.

## Creating Commands

The `ChildProcess.make` function generates a command object, which includes details such as the process name, arguments, and environment.

**Example** (Defining a Command for Directory Listing)

```ts twoslash import.meta.vitest name="creating-commands-1"
import { ChildProcess } from "effect/unstable/process"

const command = ChildProcess.make("ls", ["-al"])
const details = { command: command.command, args: command.args }
details // => { command: "ls", args: ["-al"] }
```

This command object does not execute until run by an executor.

## Running Commands

You need a `ChildProcessSpawner` to run the command, which can capture output in various formats such as strings, lines, or streams.

**Example** (Running a Command and Printing Output)

```ts twoslash
import { ChildProcess } from "effect/unstable/process"
import { ChildProcessSpawner } from "effect/unstable/process/ChildProcessSpawner"
import { NodeServices, NodeRuntime } from "@effect/platform-node"
import { Effect } from "effect"

const command = ChildProcess.make("ls", ["-al"])

// The program depends on a ChildProcessSpawner
const program = Effect.gen(function* () {
  const spawner = yield* ChildProcessSpawner
  // Runs the command returning the output as a string
  const output = yield* spawner.string(command)
  console.log(output)
})

// Provide the necessary ChildProcessSpawner
NodeRuntime.runMain(program.pipe(Effect.provide(NodeServices.layer)))
```

### Output Formats

You can choose different methods to handle command output:

| Method        | Description                                                                              |
| ------------- | ---------------------------------------------------------------------------------------- |
| `string`      | Runs the command returning the output as a string (with the specified encoding)          |
| `lines`       | Runs the command returning the output as an array of lines (with the specified encoding) |
| `stream`      | Runs the command returning the output as a stream of `Uint8Array` chunks                 |
| `streamLines` | Runs the command returning the output as a stream of lines (with the specified encoding) |

### exitCode

If you only need the exit code of a command, use `ChildProcessSpawner.exitCode`.

**Example** (Getting the Exit Code)

```ts twoslash
import { ChildProcess } from "effect/unstable/process"
import { ChildProcessSpawner } from "effect/unstable/process/ChildProcessSpawner"
import { NodeServices, NodeRuntime } from "@effect/platform-node"
import { Effect } from "effect"

const command = ChildProcess.make("ls", ["-al"])

const program = Effect.gen(function* () {
  const spawner = yield* ChildProcessSpawner
  const exitCode = yield* spawner.exitCode(command)
  console.log(exitCode)
})

NodeRuntime.runMain(program.pipe(Effect.provide(NodeServices.layer)))
// Output: 0
```

## Custom Environment Variables

You can customize environment variables in a command by using `ChildProcess.setEnv`. This is useful when you need specific variables for the command's execution.

**Example** (Setting Environment Variables)

In this example, the command runs in a shell to ensure environment variables are correctly processed.

```ts twoslash
import { ChildProcess } from "effect/unstable/process"
import { ChildProcessSpawner } from "effect/unstable/process/ChildProcessSpawner"
import { NodeServices, NodeRuntime } from "@effect/platform-node"
import { Effect } from "effect"

const command = ChildProcess.make("echo", ["-n", "$MY_CUSTOM_VAR"], {
  // Use shell to interpret variables correctly
  // on Windows and Unix-like systems
  shell: true,
}).pipe(
  ChildProcess.setEnv({
    MY_CUSTOM_VAR: "Hello, this is a custom environment variable!",
  }),
)

const program = Effect.gen(function* () {
  const spawner = yield* ChildProcessSpawner
  const output = yield* spawner.string(command)
  console.log(output)
})

NodeRuntime.runMain(program.pipe(Effect.provide(NodeServices.layer)))
// Output: Hello, this is a custom environment variable!
```

## Feeding Input to a Command

You can send input directly to a command's standard input using the `stdin` option of `ChildProcess.make`.

**Example** (Sending Input to a Command's Standard Input)

```ts twoslash
import { ChildProcess } from "effect/unstable/process"
import { ChildProcessSpawner } from "effect/unstable/process/ChildProcessSpawner"
import { NodeServices, NodeRuntime } from "@effect/platform-node"
import { Effect, Stream } from "effect"

const command = ChildProcess.make("cat", [], {
  stdin: Stream.make(new TextEncoder().encode("Hello")),
})

const program = Effect.gen(function* () {
  const spawner = yield* ChildProcessSpawner
  console.log(yield* spawner.string(command))
})

NodeRuntime.runMain(program.pipe(Effect.provide(NodeServices.layer)))
// Output: Hello
```

## Fetching Process Details

You can access details about a running process, such as `exitCode`, `stdout`, and `stderr`.

**Example** (Accessing Exit Code and Streams from a Running Process)

```ts twoslash
import { ChildProcess } from "effect/unstable/process"
import { ChildProcessSpawner } from "effect/unstable/process/ChildProcessSpawner"
import { NodeServices, NodeRuntime } from "@effect/platform-node"
import { Effect, Stream, String, pipe } from "effect"

// Helper function to collect stream output as a string
const runString = <E, R>(stream: Stream.Stream<Uint8Array, E, R>): Effect.Effect<string, E, R> =>
  stream.pipe(
    Stream.decodeText(),
    Stream.runFold(() => String.empty, String.concat),
  )

const program = Effect.gen(function* () {
  const spawner = yield* ChildProcessSpawner
  const command = ChildProcess.make("ls", [])

  const [exitCode, stdout, stderr] = yield* pipe(
    // Start running the command and return a handle to the running process
    spawner.spawn(command),
    Effect.flatMap((process) =>
      Effect.all(
        [
          // Waits for the process to exit and returns
          // the ExitCode of the command that was run
          process.exitCode,
          // The standard output stream of the process
          runString(process.stdout),
          // The standard error stream of the process
          runString(process.stderr),
        ],
        { concurrency: 3 },
      ),
    ),
  )
  console.log({ exitCode, stdout, stderr })
})

NodeRuntime.runMain(Effect.scoped(program).pipe(Effect.provide(NodeServices.layer)))
```

## Streaming stdout to process.stdout

To stream a command's `stdout` directly to `process.stdout`, you can use the following approach:

**Example** (Streaming Command Output Directly to Standard Output)

```ts twoslash
import { ChildProcess } from "effect/unstable/process"
import { ChildProcessSpawner } from "effect/unstable/process/ChildProcessSpawner"
import { NodeServices, NodeRuntime } from "@effect/platform-node"
import { Effect } from "effect"

// Create a command to run `cat` on a file and inherit stdout
const command = ChildProcess.make("cat", ["./some-file.txt"], {
  stdout: "inherit", // Stream stdout to process.stdout
})

const program = Effect.gen(function* () {
  const spawner = yield* ChildProcessSpawner
  // Get the exit code
  return yield* spawner.exitCode(command)
})

NodeRuntime.runMain(program.pipe(Effect.provide(NodeServices.layer)))
```
