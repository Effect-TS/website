### Effect v4 updates.

Effect 4.1.6 went out on Thursday, and the week brought new MCP client capabilities, more control over exporters and workers, and a broad round of fixes across cluster, workflow and SQL.

- **Additions**: Added `Worker.CloseTimeout` to configure how long workers may take to close, `Statement.SpanNameGenerator` to override SQL statement span names, `queryTextValues` on `PgClient` and `PgConnection`, and `requestTimeout` in `MssqlClientConfig`. `sql-pg` now decodes and encodes built-in PostgreSQL ranges and multiranges, `NodeChildProcessSpawner.layerProxyProcess` was added, and `Xml.elements` supports namespaces. The OTLP export queue is now bounded with configurable `maxQueueSize`, `onDrop`, `maxBatchSize` and `concurrency`, batched HTTP RPC requests are linked to caller spans in a root batch span, and `HttpApi` redacts `Redacted` values in client and server spans. The minimal Effect runtime bundle also got smaller.

- **Behavior changes**: `Match.fn` matchers are now accepted by `Match.tags`, `Match.discriminator` and the related helpers and pass their arguments to the handlers, while `Match.type` no longer passes the matched input twice to case and `orElse` handlers. `Order.clamp` returns the input instead of the bound when they compare equal, `Stream.merge` and `Channel.merge` start both input sides immediately, and the HTTP server no longer reports built-in 400 and 404 client errors to `ErrorReporter`s. The code that generates TypeScript for built-in schemas moved into `Codegen`, which makes bundles smaller for apps that use `Schema` without generating code, but code that read `annotations.toCode` from a built-in needs to use `Codegen.Module.addSchemas` instead.

- **MCP & AI**: `McpClient` can now connect with the 2025-03-26 and 2025-06-18 revisions, continue `2026-07-28` tool calls that pause for client input, and read a tool list's cache hint. `McpServer` finds tool registrations by name through an index, speeds up toolkit registration, caches `tools/list` projections and explains HTTP transport rejections in the response body. A toolkit handler's `InvalidParams` is now reported as invalid input. Anthropic refusal stop details and text documents from base64 data URLs now decode correctly, OpenRouter stream metadata keeps the serving provider, and `Chat` fixes cover replay after OpenAI image generation and history placing the answer between an approved tool call and its result.

- **Cluster & workflow**: `ClusterCron` no longer retries failed runs, and workflow activity waits are handed off promptly during shard rebalance. Fixed `Activity.retry` under `Workflow.SuspendOnFailure`, sibling child workflows not being dispatched before a durable wait suspends, parents awaiting a shared child execution not all waking, and compensation defects not being captured in terminal results. On Cloudflare, cluster Durable Objects now stay in their jurisdiction and workflow alarms are reconciled after suspension and completion. Also fixed replies stored for requests that `deleteProcessed` already removed and cluster reply handler entries lingering when their last waiter is interrupted.

- **HTTP, RPC & platform**: Fixed `HttpApiClient` crashing on non-JSON error bodies with `layerNodeHttp`, generated multipart payloads rejecting files in open object schemas, `FetchHttpClient` not resolving `globalThis.fetch` on each request, and `HttpMiddleware.cors` not sending `Access-Control-Max-Age` when `maxAge` is 0. Bun `fileWeb` responses now infer their `Content-Type` from the file name, file reads and writes support pipes and FIFOs on Node, and `NodeStdio` pauses `process.stdin` when its last consumer stops. On the OpenAPI side, endpoint names and parameter schemas are now group-local in generated `HttpApi`s.

- **SQL & persistence**: Fixed `Migrator` skipping migration id `0` on a fresh database, typed `SqlError`s when `sql-d1` prepare throws, retiring pinned `sql-pg` sessions released with an open transaction, pool slots being freed before a retired transport closes, and a leading U+FEFF in `KeyValueStore` file and SQL string values. Also compacted consumed pipeline entries in multiplexed `PgConnection`s and avoided redundant service-map merges in SQL transactions.

- **Core & performance**: The audit continued with fixes for `Pool.get` hanging after a failed acquisition, `Cron.next` and `Cron.prev` drifting by an hour across host DST changes, `Stream` async iterators dropping values during overlapping reads, `Effect.catchTag` losing tagged errors for an inline self, `ScopedCache` evicting a reloaded entry next, and `LayerRef` not rebuilding on invalidation while still borrowed. Also fixed `Atom.subscriptionRef` setters throwing while the ref is being updated, stream atoms reporting the previous run's value when a run completes empty, `String` line iterators restarting, and `Effect.catchReasons` error-channel inference. `Equal.equals` avoids uncached structural hashing, `Schema.toEquivalence` memoizes nested schemas, and `DateTime` no longer pulls in `Intl` in AOT-compiled bundles.

You can follow the full changelog in the [effect repository](https://github.com/Effect-TS/effect/commits/main).
