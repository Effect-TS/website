import { TutorialCheckpoint } from "@astrojs/starlight/components"

A request can feel slow even when every provider succeeds. Ordinary logs show
which phase finished, but they rarely show which operations overlapped or which
child kept the whole request waiting.

In this tutorial, we will keep one `POST /orders` backend local and make its
timing visible. The finished server prints a graphical waterfall after every
order:

```text title="Finished trace shape"
Trace waterfall (one block is about 20 ms)
http.post.orders    |████████████|
  pricing.calculate |████        |
  inventory.reserve |███████     |
  shipping.quote    |█████       |
  payment.authorize |       ███  |
  orders.insert     |          ██|
attributes
  order.customer_id = "customer-123"
  order.quantity = 2
```

The exact number of blocks may vary slightly with machine load. Their positions
still reveal the important structure: pricing, inventory, and shipping overlap;
inventory is the slowest of those three; payment waits for them; and storage
waits for payment.

Everything runs in one Node.js process. The providers, tracer, and waterfall
renderer are deterministic local fixtures, so the tutorial needs no public
network, credentials, collector, or dashboard.

Each step ends with a checkpoint: a short verification to complete before continuing.

## 1. See what logs leave out

You need Node.js 22.18.0 or newer. That is the minimum version used here because
Node can run this erasable TypeScript directly without another build tool.

To create the project manually, open an empty parent directory and run:

```sh title="Create the project"
mkdir see-where-a-request-spends-its-time
cd see-where-a-request-spends-its-time
npm init -y
npm pkg set type=module
npm install --save-dev @types/node@22
```

Create `server.ts` with the complete code below. The bottom half is controlled
tutorial fixture code. It simulates five local providers with stable delays;
collapse it mentally as setup rather than application logic.

```ts title="server.ts" collapse={63-111}
import { createServer } from "node:http"
import { setTimeout as sleep } from "node:timers/promises"

interface PlaceOrderRequest {
  readonly customerId: string
  readonly quantity: number
  readonly paymentToken: string
  readonly postalCode: string
}

const placeOrder = async (input: PlaceOrderRequest) => {
  const [subtotalCents, reservationId, shippingCents] = await Promise.all([
    calculatePrice(input.quantity),
    reserveInventory(input.quantity),
    quoteShipping(input.postalCode, input.quantity),
  ])
  console.log("planning finished")

  const paymentProvider = await authorizePayment(
    input.paymentToken,
    subtotalCents + shippingCents,
  )
  console.log("payment finished")

  const orderId = await insertOrder(input.customerId, reservationId)
  console.log("storage finished")

  return {
    orderId,
    status: "accepted",
    totalCents: subtotalCents + shippingCents,
    paymentProvider,
  }
}

const server = createServer(async (request, response) => {
  const sendJson = (status: number, body: unknown): void => {
    response.writeHead(status, { "content-type": "application/json" })
    response.end(JSON.stringify(body))
  }

  if (request.method !== "POST" || request.url !== "/orders") {
    sendJson(404, { error: "NotFound" })
    return
  }

  try {
    let body = ""
    for await (const chunk of request) {
      body += chunk
    }

    const order = await placeOrder(JSON.parse(body) as PlaceOrderRequest)
    sendJson(201, order)
  } catch (error) {
    console.error(error)
    sendJson(500, { error: "InternalServerError" })
  }
})

server.listen(3000, () => console.log("Listening on http://localhost:3000"))
```

## 2. Describe the same pipeline with Effect

Keep the watched server running. In the second terminal pane, install Effect:

```sh title="Install Effect"
npm install effect@4.0.0-beta.104
```

Replace `server.ts` with this complete version. The response, delays, and log
lines stay the same. Only the way we describe and run the provider pipeline
changes.

```ts title="server.ts" collapse={81-129} ins={3,12-50,69-71}
import { createServer } from "node:http"
import { setTimeout as sleep } from "node:timers/promises"
import { Effect } from "effect"

interface PlaceOrderRequest {
  readonly customerId: string
  readonly quantity: number
  readonly paymentToken: string
  readonly postalCode: string
}

const placeOrder = (input: PlaceOrderRequest) =>
  Effect.all(
    [
      Effect.tryPromise((signal) => calculatePrice(input.quantity, { signal })),
      Effect.tryPromise((signal) =>
        reserveInventory(input.quantity, { signal }),
      ),
      Effect.tryPromise((signal) =>
        quoteShipping(input.postalCode, input.quantity, { signal }),
      ),
    ],
    { concurrency: "unbounded" },
  ).pipe(
    Effect.flatMap(([subtotalCents, reservationId, shippingCents]) => {
      console.log("planning finished")
      return Effect.tryPromise((signal) =>
        authorizePayment(input.paymentToken, subtotalCents + shippingCents, {
          signal,
        }),
      ).pipe(
        Effect.flatMap((paymentProvider) => {
          console.log("payment finished")
          return Effect.tryPromise((signal) =>
            insertOrder(input.customerId, reservationId, { signal }),
          ).pipe(
            Effect.map((orderId) => {
              console.log("storage finished")
              return {
                orderId,
                status: "accepted",
                totalCents: subtotalCents + shippingCents,
                paymentProvider,
              }
            }),
          )
        }),
      )
    }),
  )

const server = createServer(async (request, response) => {
  const sendJson = (status: number, body: unknown): void => {
    response.writeHead(status, { "content-type": "application/json" })
    response.end(JSON.stringify(body))
  }

  if (request.method !== "POST" || request.url !== "/orders") {
    sendJson(404, { error: "NotFound" })
    return
  }

  try {
    let body = ""
    for await (const chunk of request) {
      body += chunk
    }

    const order = await Effect.runPromise(
      placeOrder(JSON.parse(body) as PlaceOrderRequest),
    )
    sendJson(201, order)
  } catch (error) {
    console.error(error)
    sendJson(500, { error: "InternalServerError" })
  }
})

server.listen(3000, () => console.log("Listening on http://localhost:3000"))
```

The first `Effect.tryPromise` call creates an Effect value. An Effect is a value
that describes a computation. Creating it, combining it with other Effects, or
passing it through `pipe` does not call a provider. The providers run only when
the request handler reaches `Effect.runPromise`.

TypeScript infers this explanatory type for `placeOrder(input)`:

```ts title="Inferred type, not code to paste"
Effect.Effect<
  {
    orderId: string
    status: string
    totalCents: number
    paymentProvider: string
  },
  Cause.UnknownError
>
```

The first type argument is the successful order value. The second is the error
channel, which describes expected ways the computation can fail. Here, an
unclassified rejected Promise becomes `Cause.UnknownError`. Interruption is
cancellation of a running computation and is separate from that error channel.
An unexpected bug is called a defect and is also separate from an expected
failure.

[`Effect.Effect`](/docs/v4/api/effect/Effect#Effect) is the type of an Effect
description. In this pipeline, its success type is the order object and its
error type is
[`Cause.UnknownError`](/docs/v4/api/effect/Cause#UnknownError-interface).
`Cause.UnknownError` is Effect's built-in wrapper for an unclassified Promise
rejection, and its `cause` property preserves the original rejected value.

[`Effect.tryPromise`](/docs/v4/api/effect/Effect#tryPromise) adapts a function
that creates a Promise. The function stays lazy until the Effect runs, a
resolved Promise becomes a success, and a rejection enters the error channel.
Effect supplies an `AbortSignal`, which this code forwards to every local
provider so interruption can cancel its timer.

[`Effect.all`](/docs/v4/api/effect/Effect#all) combines several Effects and
returns their success values in the same order. With
`concurrency: "unbounded"`, the three planning Effects can run at the same time
instead of waiting for one another.

`pipe` passes the combined description through transformations from top to
bottom. It does not run the computation.

[`Effect.flatMap`](/docs/v4/api/effect/Effect#flatMap) uses a successful value
to choose the next Effect. Payment is described only after all three planning
values exist, and storage is described only after payment succeeds.
[`Effect.map`](/docs/v4/api/effect/Effect#map) transforms only the success value
and leaves the error channel unchanged. Here, it turns the stored order id into
the HTTP response object.

Finally, [`Effect.runPromise`](/docs/v4/api/effect/Effect#runPromise) runs the
complete description at the HTTP boundary and returns a Promise. That Promise
resolves with the order when the Effect succeeds and rejects if the Effect does
not succeed. The runner can also accept an external `AbortSignal` to observe
cancellation, although this server does not need one yet.

Wait for `node --watch` to reload, then send the same request. It still returns
`201` and prints the same three application log lines. We changed the execution
description without changing its observable result.

## 3. Record the whole request as one span

A span is a timed record of one operation. It has a name, start and end times,
an optional parent, and attributes. A trace is the tree formed by a root span
and its children.

The next complete file supplies a small local tracer and waterfall renderer in
the collapsed fixture section. The tracer records spans in memory. The renderer
sorts them, rounds their positions to 20 millisecond blocks, and prints the
result after the Effect finishes. You do not need to design or edit either
fixture during this tutorial.

Add that fixture and wrap the order pipeline in a root span:

```ts title="server.ts" collapse={84-132} ins={3,69-71,73-74,134-199}

const recordedSpans: Array<Tracer.NativeSpan> = []

const localTracer = Tracer.make({
  span(options) {
    const span = new Tracer.NativeSpan(options)
    recordedSpans.push(span)
    return span
  },
})

const renderLatestTrace = (): string => {
  const spans = recordedSpans.splice(0)
  const root = spans.find((span) => span.parent._tag === "None")

  if (root === undefined || root.status._tag !== "Ended") {
    return "Trace waterfall unavailable"
  }

  const quantum = 20_000_000n
  const toColumn = (nanoseconds: bigint): number =>
    Number((nanoseconds + quantum / 2n) / quantum)
  const columns = Math.max(
    1,
    toColumn(root.status.endTime - root.status.startTime),
  )

  const depthOf = (span: Tracer.NativeSpan): number => {
    let depth = 0
    let parent = span.parent._tag === "Some" ? span.parent.value : undefined

    while (parent?._tag === "Span") {
      depth += 1
      parent = parent.parent._tag === "Some" ? parent.parent.value : undefined
    }

    return depth
  }

  const completed = spans.flatMap((span) =>
    span.status._tag === "Ended" ? [{ span, status: span.status }] : [],
  )
  const labels = completed.map(
    ({ span }) => `${"  ".repeat(depthOf(span))}${span.name}`,
  )
  const labelWidth = Math.max(...labels.map((label) => label.length))
  const lines = completed.map(({ span, status }, index) => {
    const offset = toColumn(status.startTime - root.status.startTime)
    const available = Math.max(1, columns - offset)
    const length = Math.min(
      available,
      Math.max(1, toColumn(status.endTime - status.startTime)),
    )
    const bar = `${" ".repeat(offset)}${"█".repeat(length)}`.padEnd(columns)
    return `${labels[index]!.padEnd(labelWidth)} |${bar}|`
  })

  const attributes = [...root.attributes.entries()]
    .sort(([left], [right]) => left.localeCompare(right))
    .map(([key, value]) => `  ${key} = ${JSON.stringify(value)}`)

  return [
    "Trace waterfall (one block is about 20 ms)",
    ...lines,
    ...(attributes.length > 0 ? ["attributes", ...attributes] : []),
  ].join("\n")
}
```

[`Tracer.make`](/docs/v4/api/effect/Tracer#make) creates a tracer value from the
supplied implementation. This fixture stores every span created during one
request in memory. Each one is a
[`Tracer.NativeSpan`](/docs/v4/api/effect/Tracer#NativeSpan), Effect's stable
in-memory span implementation. It records the parent, attributes, start time,
end time, and completion status that the renderer reads.

[`Effect.withSpan`](/docs/v4/api/effect/Effect#withSpan) wraps the order Effect
in a named span and closes that span when the Effect ends, including after
failure, interruption, or a defect. `root: true` starts a new trace, and
`kind: "server"` identifies request-handling work.
[`Effect.withTracer`](/docs/v4/api/effect/Effect#withTracer) runs this Effect
using the supplied tracer. It changes where spans are recorded without adding a
tracer requirement to `placeOrder`.

## 4. Give each operation its own bar

The root tells us total request time. To explain that total, add a child span
around each provider Effect. The three Effects inside `Effect.all` remain
concurrent. Payment and storage remain sequential because their `flatMap`
callbacks cannot produce the next Effect until the previous success exists.

```ts title="server.ts" collapse={88-203} ins={15-17,20,23,34,40}

    ({ span }) => `${"  ".repeat(depthOf(span))}${span.name}`,
  )
  const labelWidth = Math.max(...labels.map((label) => label.length))
  const lines = completed.map(({ span, status }, index) => {
    const offset = toColumn(status.startTime - root.status.startTime)
    const available = Math.max(1, columns - offset)
    const length = Math.min(
      available,
      Math.max(1, toColumn(status.endTime - status.startTime)),
    )
    const bar = `${" ".repeat(offset)}${"█".repeat(length)}`.padEnd(columns)
    return `${labels[index]!.padEnd(labelWidth)} |${bar}|`
  })

  const attributes = [...root.attributes.entries()]
    .sort(([left], [right]) => left.localeCompare(right))
    .map(([key, value]) => `  ${key} = ${JSON.stringify(value)}`)

  return [
    "Trace waterfall (one block is about 20 ms)",
    ...lines,
    ...(attributes.length > 0 ? ["attributes", ...attributes] : []),
  ].join("\n")
}
```

Each new `Effect.withSpan` call wraps only one provider Effect. Because the root
span is active while `placeOrder` runs, Effect automatically records these five
spans as its children. Concurrent children keep that same parent.

Wait for the reload and place the order again. The response remains `201`. The
trace now has this shape:

```text title="Expected waterfall shape"
Trace waterfall (one block is about 20 ms)
http.post.orders     |████████████|
  pricing.calculate  |████        |
  inventory.reserve  |███████     |
  shipping.quote     |█████       |
  payment.authorize  |       ███  |
  orders.insert      |          ██|
```

Read the bars from left to right:

- pricing, inventory, and shipping begin together because `Effect.all` runs
  them concurrently;
- inventory is the planning bottleneck because its bar extends farthest;
- payment begins near inventory's end, after every planning result is ready;
- storage begins after payment finishes.

The planning stage takes roughly the duration of inventory, not the sum of all
three children. The waterfall turns that concurrency and bottleneck into a
shape you can inspect without correlating timestamps by hand.

## 5. Attach the request context you will search for

Names and bars explain structure, but an operator also needs to know which
request produced a trace. Add the customer id and quantity to the active root
span before `placeOrder` runs. Keep the payment token out of telemetry because
credentials and secrets do not belong in span attributes.

```ts title="server.ts" collapse={95-210} ins={73-80}
import { createServer } from "node:http"
import { setTimeout as sleep } from "node:timers/promises"
import { Effect, Tracer } from "effect"

interface PlaceOrderRequest {
  readonly customerId: string
  readonly quantity: number
  readonly paymentToken: string
  readonly postalCode: string
}

const placeOrder = (input: PlaceOrderRequest) =>
  Effect.all(
    [
      Effect.tryPromise((signal) =>
        calculatePrice(input.quantity, { signal }),
      ).pipe(Effect.withSpan("pricing.calculate")),
      Effect.tryPromise((signal) =>
        reserveInventory(input.quantity, { signal }),
      ).pipe(Effect.withSpan("inventory.reserve")),
      Effect.tryPromise((signal) =>
        quoteShipping(input.postalCode, input.quantity, { signal }),
      ).pipe(Effect.withSpan("shipping.quote")),
    ],
    { concurrency: "unbounded" },
  ).pipe(
    Effect.flatMap(([subtotalCents, reservationId, shippingCents]) => {
      console.log("planning finished")
      return Effect.tryPromise((signal) =>
        authorizePayment(input.paymentToken, subtotalCents + shippingCents, {
          signal,
        }),
      ).pipe(
        Effect.withSpan("payment.authorize"),
        Effect.flatMap((paymentProvider) => {
          console.log("payment finished")
          return Effect.tryPromise((signal) =>
            insertOrder(input.customerId, reservationId, { signal }),
          ).pipe(
            Effect.withSpan("orders.insert"),
            Effect.map((orderId) => {
              console.log("storage finished")
              return {
                orderId,
                status: "accepted",
                totalCents: subtotalCents + shippingCents,
                paymentProvider,
              }
            }),
          )
        }),
      )
    }),
  )

const server = createServer(async (request, response) => {
  const sendJson = (status: number, body: unknown): void => {
    response.writeHead(status, { "content-type": "application/json" })
    response.end(JSON.stringify(body))
  }

  if (request.method !== "POST" || request.url !== "/orders") {
    sendJson(404, { error: "NotFound" })
    return
  }

  try {
    let body = ""
    for await (const chunk of request) {
      body += chunk
    }

    const input = JSON.parse(body) as PlaceOrderRequest
    const orderEffect = Effect.flatMap(
      Effect.annotateCurrentSpan({
        "order.customer_id": input.customerId,
        "order.quantity": input.quantity,
      }),
      () => placeOrder(input),
    ).pipe(
      Effect.withSpan("http.post.orders", { root: true, kind: "server" }),
      Effect.withTracer(localTracer),
    )
    const order = await Effect.runPromise(orderEffect)
    console.log(renderLatestTrace())
    sendJson(201, order)
  } catch (error) {
    console.error(error)
    sendJson(500, { error: "InternalServerError" })
  }
})

server.listen(3000, () => console.log("Listening on http://localhost:3000"))

  span(options) {
    const span = new Tracer.NativeSpan(options)
    recordedSpans.push(span)
    return span
  },

const renderLatestTrace = (): string => {
  const spans = recordedSpans.splice(0)
  const root = spans.find((span) => span.parent._tag === "None")

  if (root === undefined || root.status._tag !== "Ended") {
    return "Trace waterfall unavailable"
  }

  const quantum = 20_000_000n
  const toColumn = (nanoseconds: bigint): number =>
    Number((nanoseconds + quantum / 2n) / quantum)
  const columns = Math.max(
    1,
    toColumn(root.status.endTime - root.status.startTime),
  )

  const depthOf = (span: Tracer.NativeSpan): number => {
    let depth = 0
    let parent = span.parent._tag === "Some" ? span.parent.value : undefined

    while (parent?._tag === "Span") {
      depth += 1
      parent = parent.parent._tag === "Some" ? parent.parent.value : undefined
    }

    return depth
  }

  const completed = spans.flatMap((span) =>
    span.status._tag === "Ended" ? [{ span, status: span.status }] : [],
  )
  const labels = completed.map(
    ({ span }) => `${"  ".repeat(depthOf(span))}${span.name}`,
  )
  const labelWidth = Math.max(...labels.map((label) => label.length))
  const lines = completed.map(({ span, status }, index) => {
    const offset = toColumn(status.startTime - root.status.startTime)
    const available = Math.max(1, columns - offset)
    const length = Math.min(
      available,
      Math.max(1, toColumn(status.endTime - status.startTime)),
    )
    const bar = `${" ".repeat(offset)}${"█".repeat(length)}`.padEnd(columns)
    return `${labels[index]!.padEnd(labelWidth)} |${bar}|`
  })

  const attributes = [...root.attributes.entries()]
    .sort(([left], [right]) => left.localeCompare(right))
    .map(([key, value]) => `  ${key} = ${JSON.stringify(value)}`)

  return [
    "Trace waterfall (one block is about 20 ms)",
    ...lines,
    ...(attributes.length > 0 ? ["attributes", ...attributes] : []),
  ].join("\n")
}
```

[`Effect.annotateCurrentSpan`](/docs/v4/api/effect/Effect#annotateCurrentSpan)
describes adding one or more attributes to the span active when this Effect
runs. Here, the root is already active, so the customer id and quantity are
attached to `http.post.orders` before the provider pipeline begins.

Send the same request once more. The bars keep the same shape, and the renderer
adds the two sorted attributes below them:

```text title="Expected request attributes"

  order.customer_id = "customer-123"
  order.quantity = 2
```

The trace now answers both kinds of question. Its bars explain where the request
spent time; its attributes identify the request that produced those bars. In a
production exporter, the same span names and attributes can be sent to a trace
backend, while the order pipeline remains independent of that destination.
