# Tutorial Order Processing

This context defines a stable order-processing language for tutorials that
choose this scenario. Prefer it when it fits the learning outcome naturally;
use another scenario when that makes the lesson clearer or more realistic.
Whenever a tutorial reuses a term from this model, keep the meaning defined
here.

## Language

**Customer**:
A person or organization that asks the system to quote and place orders.
_Avoid_: Client, buyer, account

**Customer ID**:
The stable identifier of a Customer.
_Avoid_: User ID, account ID

**Order Line**:
A requested quantity of one catalog item, identified by its SKU.
_Avoid_: Item, product line

**Quote**:
The priced Order Lines, shipping cost, currency, and resulting total for one
delivery destination.
_Avoid_: Estimate, price response

**Order Request**:
A Customer's request to buy Order Lines, deliver them to a destination, and pay
with a referenced payment method.
_Avoid_: Submission, transaction

**Order**:
A purchase recorded by the system after inventory, payment, and persistence
have succeeded.
_Avoid_: Request, transaction

**Order ID**:
The identifier generated by the system while processing an Order Request.
_Avoid_: External order ID, operation ID

**Accepted Order**:
An Order whose inventory has been reserved, payment authorized, and record
stored successfully.
_Avoid_: Stored order, completed order

**Accepted At**:
The instant when an Order became an Accepted Order.
_Avoid_: Created at, completed at

**Order Labels**:
A set of distinct labels attached to an Order for classification.
_Avoid_: Tags, categories

**Payment Token**:
An opaque reference to a Customer's payment method. Its value is confidential
and must not be exposed in logs, traces, or responses.
_Avoid_: Card token, payment ID

**Payment Authorization**:
The provider's confirmation that payment for an Order may proceed.
_Avoid_: Payment, charge

**Inventory Reservation**:
The system's temporary claim on the stock needed by an Order.
_Avoid_: Inventory lock

**Imported Order**:
An order record received from an external system for validation and import.
_Avoid_: Order Request

**External Order ID**:
The identifier assigned to an Imported Order by its source system.
_Avoid_: Order ID
