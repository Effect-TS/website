One key feature that sets Effect apart is how it leverages structured concurrency to provide features such as async cancellation and safe resource management, making it easier to build robust, scalable, and efficient programs.

### Effect v4 RC final updates.

This was the final week of the Release Candidate cycle. The last stretch of RC hardening focused on concurrency correctness, Schema internals, and cluster reliability.

- **Concurrency correctness**: Fixed `Effect.race` losers being left running when the race ends during startup, fixed a lost failure during concurrent layer interruption, fixed the `Queue` batch taker wake loop on partial offers, and fixed `AtomRegistry` missing updates through stale nodes and leaked superseded builds.

- **Schema**: Stopped Schema unions from resolving candidate parsers on every decode, inlined checked sources of Schema JIT transformations, fixed Schema projection check preservation, fixed Schema brand identifier typing, and made `Schema.brand` type-only. Also clarified schema branding guidance in the v3-to-v4 migration reference.
- **Cluster & workflow**: Guarded workflow replies against stale concurrent resets, retried failed cluster workflow run resets, and treated infinite `PubSub` capacity as unbounded.

- **RPC**: Failed in-flight RPC streams after a missed socket pong, fixed flat RPC client and `AtomRpc` inference for a union of tags, and fixed synchronous concurrent `Atom.fn` results.

- **HttpApi**: Added per-slot `ParseOptions` annotations with a `ParseOptions` fallback, and closed server WebSockets according to handler exit.

- **Other fixes**: Fixed `MutableHashMap` key retention on equal-key cache refresh, fixed the encoded RPC interrupt fiber ID type for JSON null, and normalized partition result order across all modules.

And with that, the RC cycle wraps up. Thank you to everyone who tested the beta and RC builds and helped shape the release with bug reports, feedback, and contributions.

You can follow the full changelog in the [effect repository](https://github.com/Effect-TS/effect/commits/main).

To catch up on more updates, check out [Effect v4 Updates](https://www.effect.website/blog?category=effect-v4-updates), starting from the recently published [Effect v4 RC: August 2026 Updates](https://www.effect.website/blog/effect-v4-rc-august-recap).
