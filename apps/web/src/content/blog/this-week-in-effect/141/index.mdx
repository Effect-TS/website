### Effect v4 updates.

A week of new modules and a big push on `EventLog`, alongside the ongoing stream of fixes across the codebase. Here are the most notable changes.

- **Additions**: Added a native `McpClient`, `effect/persistence/CircuitBreaker`, `Schema.toStandardJSONSchemaV1`, a `TextDiff` module for minimal edit scripts and unified diffs, and Cloudflare AI Gateway support. Streaming encodings now include zip, XML and `JsonArray` for large JSON arrays, and `Base64Url.encodePadded` was added. Also added typed HTTP date and `Retry-After` header values to `Headers`, `FileSystem.lstat`, `Flag.withNegation` and `Flag.withoutNegation`, `Command.validate` for rules across CLI flags, a `skipInitialRun` option for seeded effect atoms, and deterministic concurrent property checking for tests.

- **EventLog**: Entries are now encrypted in batches and get ids from a hybrid logical clock, with `EventLog.writeMany` and monotonic entry ids. Conflicts are ordered by entry id across journals and server, writes are acknowledged rather than echoed to the writer, and compaction can now drop entries only. `SqlEventJournal` gained upload checkpoints and secondary indexes, and remote replay was sped up with cached conflict payloads, indexed lookups and less per-entry overhead. Also fixed out-of-order unencrypted replication, duplicate encrypted SQL event broadcasts, and several IndexedDB journal and checkpoint issues.

- **Cluster & workflow**: Fixed shard release stalling on a defect restart, `ClusterCron` initial scheduling recovery, duplicate workflow compensations after memory-engine replays, and interrupts being lost while a workflow run saves its `Suspended` reply. Stalled shard releases are now warned about repeatedly, with a new releasing-shards gauge and a shard release duration timer. Cluster storage reads also wake up when an entity registers.

- **HTTP, RPC & platform**: Added opt-in request batching to the HTTP RPC client protocol, streaming request payload support to `HttpApi`, and HTTP/2 servers in `NodeHttpServer`. Forwarded headers now require a trusted proxy policy. Fixed `HttpClient.followRedirects` dying on an invalid `Location` header, `basicAuth` credentials not being encoded as UTF-8, multipart `Content-Disposition` filename decoding, and `NodeHttpServer` ending failed streamed responses as complete. On the runtime side, fixed Bun WebSocket interruption on close, Deno response failures and `Socket.readerString` corrupting characters split across frames.

- **SQL & AI**: `PgClient` gained an `onAcquire` hook and an `acquireTimeout`, PostgreSQL server errors are preserved when the connection closes, and `SqlClient` callbacks now run after the outermost transaction commits. SQL `PersistedQueue` settlements are fenced by acquisition. On the AI side, added the OpenAI `safety_identifier` and `prompt_cache_retention` request options plus prompt cache breakpoints on image and file input, and fixed composed tool failure causes being lost and retry classification for provider response decoding failures.

- **Core, Schema & collections**: The audit kept going with fixes for `Cause.pretty` on cyclic cause chains, `Fiber.runIn` and `Effect.forkIn` hanging, scoped forks running after scope closure, `Effect.repeat` turning a `Done` failure into a success, and `Stream.retry` slowing down on every retry. Defects now take precedence over typed failures in more recovery operators. Schema fixes cover `Schema.Tuple` encoding with omitted optional elements, Unicode casing checks, `Schema.toFormatter` and `Schema.toTaggedUnion`. Layers are now memoized by identity, and finite number and base64 validation run in linear time.

- **Config, CLI & parsers**: Fixed YAML block scalars with tabs, `Ini.parse` dropping a trailing backslash, TOML empty quoted keys, `Config.schema` dropping record keys for non-string key schemas, `OTEL_RESOURCE_ATTRIBUTES` values containing `=`, and several CLI lexer edge cases with clustered short options. Also fixed `DateTime.formatIsoDate` for extended years, `zoneFromString` rejecting `GMT`, and nanosecond precision in `Duration` strings and inputs.

You can follow the full changelog in the [effect repository](https://github.com/Effect-TS/effect/commits/main).

To catch up on more updates, check out [Effect v4 Updates](https://www.effect.website/blog?category=effect-v4-updates), starting from the recently published [Effect v4 RC: September 2026 Updates](https://effect.website/blog/effect-v4-rc-september-recap).
