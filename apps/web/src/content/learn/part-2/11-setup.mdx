This guide gets the reflex starter project running on your machine and starts
the trace viewer. When you finish it, the first local lesson,
[Using FileSystem and NodeRuntime.runMain](/learn/part-2/11-your-program-your-entrypoint),
can start straight away.

This page sits between [Part 1 review](/learn/part-1/10-checkpoint) and the
first local lesson. If you want to take Part 1 on your machine instead of in
the browser, do steps 1 and 2 now and run each lesson with `pnpm lesson <n>`.
Part 1 does not use the trace viewer, so come back for steps 3 and 4 after the
review.

## Before you start

The 15 minutes assume you already have these installed:

- Node 22.16 or newer
- pnpm, or corepack to provide it (`corepack enable`)
- git
- a browser
- for the trace viewer, one of: macOS, Linux with glibc 2.39 or newer
  (Ubuntu 24.04+, Debian 13+, Fedora 40+), or Docker

Windows through WSL2 is untested.

## 1. Get the starter

```sh
npx degit Effect-TS/website/courses/reflex reflex
cd reflex
```

`degit` copies the directory without the website's git history. `reflex` is
now a project of its own. Commit to it as you go if you like.

## 2. Install the dependencies

```sh
pnpm install
```

The Effect packages are pinned to exact versions. They are the versions every
lesson, checkpoint and test was checked against.

## 3. Check your machine and start the viewer

```sh
pnpm run doctor --viewer
```

Type the `run`. pnpm has a built-in `doctor` command of its own, and a bare
`pnpm doctor` runs that one instead of the starter's.

The first time, the doctor downloads otel-desktop-viewer v0.6.0 into
`.viewer/`. It prints one line per requirement, then starts the viewer:

```text
Downloading https://github.com/CtrlSpice/otel-desktop-viewer/releases/download/v0.6.0/otel-desktop-viewer_linux_amd64.tar.gz
✓ node    v22.16.0
✓ pnpm    on PATH
✓ git     on PATH
✓ viewer  otel-desktop-viewer v0.6.0 in .viewer/

All set.
otel-desktop-viewer v0.6.0 (/home/you/reflex/.viewer/otel-desktop-viewer)
  UI:        http://localhost:8000
  OTLP HTTP: http://localhost:4318
Press Ctrl-C to stop.
```

Leave this terminal running. Do everything else in a second one.

If the binary cannot run on your machine, for example on Linux older than
glibc 2.39, the viewer line says Docker instead, and the same version runs in
a container.

A line marked `✗` says what is missing and what to install. Fix it, then run
`pnpm run doctor --viewer` again.

## 4. Run the Part 1 file

In a second terminal, in the same directory:

```sh
pnpm tsx src/run-once.ts
```

`src/run-once.ts` is the file from Part 1 review. It prints the same three
alert lines and three skip lines you saw in the browser:

```text
expense 1200 over 500
expense 1200 under 5000
expense 1200 over 1000
skip: missing field amount
skip: missing field amount
skip: missing field amount
```

Each line is prefixed with a timestamp and `INFO`.

Now open [http://localhost:8000](http://localhost:8000). The viewer is
running and its trace list is empty. Nothing in the starter sends it traces
yet. You wire that up yourself in
[Exporting traces with OtlpTracer](/learn/part-2/16-the-picture-you-already-know).

If the page loads and the six lines printed, setup is done.
[Reading a trace in the viewer](/learn/part-2/trace-viewer) describes what you
will see there once traces arrive.

## Later sessions

The download happens once. After that:

- `pnpm viewer` starts the viewer again, without the checks.
- `pnpm run doctor` runs the checks without downloading or starting anything.
  This is the form CI uses.

## If the viewer will not start

Troubleshooting is outside the 15 minutes. The doctor checks the Node version,
pnpm, git, and whether the viewer can run here as a binary or through Docker.
It does not install Node, pnpm or Docker for you.

This guide does not cover proxies, firewalls, ports 8000 or 4318 already in
use, or running natively on Windows. If the viewer will not start at all, keep
going. Part 1 and the first five local lessons work without it. You need it
from [Exporting traces with OtlpTracer](/learn/part-2/16-the-picture-you-already-know)
on.
