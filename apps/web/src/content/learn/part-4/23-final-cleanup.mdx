Since lesson 11, every lesson has added a layer exactly where it was needed.
The server's stack grew in `src/server/main.ts`, one `Layer.provide` at a time.
The CLI's stack grew inline, in its run line. Both work. But if someone asked
you "what does this program run on?", neither is a place you'd think to look.

Before the challenge, you'll put both stacks in one file. It's a short lesson,
and nothing changes about what the program does.

## Moving the stacks into Layers.ts

`cli`:

The layers themselves haven't changed, only where they live. The order is the
one you built up over the course. Each `Layer.provide` supplies what the layers
above it need, so the Engine is built after the stores and SQLite, and closed
before them.

## Smaller entrypoints

With the stacks gone, each entrypoint shrinks to what an entrypoint is for.

The CLI's run line becomes `Effect.provide(Layers.cli)`, its only provide.

You'll still see `Effect.provideService` calls inside the Engine. Leave them
where they are. They hand a single call a service the Engine already holds,
which is a different job from building the program's layers.

To check your work, make sure `pnpm check` and `pnpm test` pass. Then repeat
the lesson 22 run from an empty `reflex.db`. Your server should give the same
four rows.

## Checkpoint
