### Effect v4 updates.

Effect 4.1.3 and 4.1.4 went out this week, alongside a wave of new AI providers and a long list of fixes across the platform packages.

- **Additions**: Added an Amazon Bedrock provider for Effect AI, AG-UI protocol support in `effect/ai`, and workload identity federation for the Anthropic, OpenAI and OpenRouter providers. Cluster sharding now runs on Cloudflare Durable Objects, and `effect/protobuf` adds `ProtobufReader` and `ProtobufWriter`, now used to encode OTLP protobuf. Also added `CommandSpec` for documenting `effect/cli` command paths, `HttpApi.RedactedNames` for span redaction of query and header names, buffered response encoding and declared header schemas for `HttpApi`, an `allowEmpty` option for `generateObject`, and `Schema.Enum` parts in `Schema.TemplateLiteral`.

- **Utilities**: Added `nthRoot` and `nthRootUnsafe` to `BigInt` and `Rational`, `Base64.encodeUnpadded` and `Base64.decodeLenient`, `String.isWellFormed` and `String.toWellFormed`, and `TextDiff.hunks` to group a line diff into hunks as data. `DateTime.make` now accepts the `UT`, `UTC` and `US` zone abbreviations, as `Date.parse` does.

- **AI providers**: Fixed a long list of OpenRouter issues, including tool call fragments and streams that end before a tool call is complete, refusals reported as content-filter finish metadata, and base64 images and files sent as data URLs. For OpenAI-compatible providers, PDFs are now sent as file parts, null optional fields are accepted and the developer role is only sent to OpenAI reasoning models. Structured output now handles optional records and tuples and emits a single null branch for properties that already accept null. Anthropic fixes cover non-strict tool schemas, citations without a file id and all generated effort levels.

- **MCP**: Restored MCP Skills support on legacy protocol revisions. Fixed resource reads dropping the registered MIME type, subscription shutdown and exit codes after stdin EOF, and progress notifications continuing after their request ends. List cursors the server never issued are now rejected, and MCP tools are hidden before parameter headers are validated.

- **SQL & persistence**: Statements and driver-level transaction lookups from a fiber that outlives its transaction now fail instead of leaking, nested transactions waiting for a savepoint can be interrupted, and savepoint release is skipped after an ancestor ends during rollback. Fixed PostgreSQL transport retirement after scope release, an unregistered PostgreSQL value failing more than the query, `sql-mssql` binding and `SqlModel` repository updates on SQL Server, and `SqlClient.withoutTransforms` keeping query name transforms.

- **HTTP, RPC & CLI**: `HttpClientError` URLs are now redacted with the redaction names active when the error is created, and requests with no body return an empty stream. Fixed `NodeHttpServer` shutdown hanging while WebSocket clients are connected, `HttpStaticServer` mishandling quoted commas in `If-None-Match`, `Headers.fromInput` dropping repeated names, and framed HTTP responses not being drained while dispatching an RPC batch. On the CLI side, fixed the wizard repeating flags typed before `--wizard`, completion for subcommand names containing colons, repeatable flags in shell completions and the minus sign in number prompts.

- **Core & performance**: The audit carried on with fixes for `Stream.filterEffect` counting indices per chunk instead of across the stream, `Pool` usage TTL idle cleanup, `ScopedCache.get` returning a released value when the cache closes during a lookup, workflow cleanup ordering on early interruption, and `Match.tags` and `Match.discriminators` calling an undefined handler. `Semaphore` queues no longer cost the square of their length, and `SchemaBinary` captures fewer failure stacks. Also fixed `TestClock` interrupting masked finalizers, renamed time zones keeping their name in `DateTime`, `ConfigProvider` environment snapshot timing, `Csv` decoders dropping records parsed before an error, `Rational` arithmetic not cancelling common factors, and `OtlpTracer` marking successful spans as `Ok` instead of leaving the status unset.

You can follow the full changelog in the [effect repository](https://github.com/Effect-TS/effect/commits/main).
