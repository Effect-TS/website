The `Schema.toFormatter` function is used to create pretty printers that generate a formatted string representation of values based on a schema.

**Example** (Pretty Printer for a Struct Schema)

```ts twoslash import.meta.vitest name="schema-to-pretty-printer-1"
import { Schema } from "effect"

const Person = Schema.Struct({
  name: Schema.String,
  age: Schema.Number,
})

// Create a pretty printer for the schema
const PersonPretty = Schema.toFormatter(Person)

// Format and print a Person object
console.log(PersonPretty({ name: "Alice", age: 30 }))
/*
Output:
'{ "name": "Alice", "age": 30 }'
*/
```

## Customizing Pretty Printer Generation

You can customize how the pretty printer formats output by using the `toFormatter` annotation within your schema definition.

The `toFormatter` annotation takes any type parameters provided (`typeParameters`) and formats the value into a string.

**Example** (Custom Pretty Printer for Numbers)

```ts twoslash import.meta.vitest name="customizing-pretty-printer-generation-1"
import { Schema } from "effect"

// Define a schema with a custom pretty annotation
const schema = Schema.Number.pipe(
  Schema.overrideToFormatter(() => (value) => `my format: ${value}`),
)

// Create the pretty printer
const customPrettyPrinter = Schema.toFormatter(schema)

// Format and print a value
console.log(customPrettyPrinter(1))
// Output: "my format: 1"
```
