Welcome back to This Week in Effect, your weekly update of the latest developments in the Effect community and ecosystem.

### Effect v4 updates.

Effect 4.1 is out, and the work on `main` has carried on since the release. This recap covers what landed after 4.1, including the fixes shipped in 4.1.1 (October 30) and 4.1.2.

- **Additions**: Added JSON5 and JSONC parsers, fixed-width integer schemas for `SchemaBinary`, an `onRejection` option for `CircuitBreaker.execute` and probe context for `CircuitBreaker` classifiers, and MCP discovery limits with configurable toolkits. Non-strict Anthropic tools can now use recursive parameters, SQL transaction control statements and connection waits are now traced, and `Glob.match` got faster.

- **Cluster & workflow**: Defect restart backoff is now isolated per entity and reset after recovery, and cluster sends from `WithTransaction` handlers are notified after commit. Fixed `ClusterWorkflowEngine` blocking shard release on pending resume interrupts, parent workflows not resuming when a suspended child is interrupted, and persisted success replies surviving a rolled back request transaction.

- **MCP & RPC**: Fixed `McpServer` declared tool failures that are not JSON, toolkit results whose encoded value is not JSON, middleware running in the wrong place when combined, and MCP `2026-07-28` listings failing for resources, templates and prompts registered as plain objects. On the RPC side, discarded calls no longer hang on transport errors, `RpcClient` no longer acknowledges dropped stream chunks on interruption, and one crashed pool worker no longer fails calls on healthy workers.

- **HTTP, SQL & platform**: Fixed `withCookiesRef` not sending cookies when the URL is completed after it, `HttpApiSchema.StreamSse` data now being encoded with its JSON codec, and generated OpenAPI clients with unescaped spec names. `PgClient` now rolls back transactions whose prepared statements went missing, remote libSQL clients allow concurrent statements, and `NodeRedis` acquisition is interruptible and finalizes pending connections correctly, with the `redis` peer minimum raised to 5.1.0.

- **Core & runtime fixes**: The audit continued with fixes for `Effect.request` retaining completed request context (the batch pool was removed), span references now released when fibers exit, `Pool.get` hanging in a finalizer of the pool's own scope, `AtomRegistry.subscribe` never notifying for an unread derived atom, and `Iterable.unfold`, `takeWhile` and `filterMapWhile` staying exhausted after completion. Also fixed `Schedule.fixed`, `Schedule.windowed` and `Schedule.cron` zero delays, `DateTime` offsets when rounding inside a repeated hour, rate limiter zero limits and expired keys, Unicode normalization in domain names, and `Path.format` missing extension dots.

You can follow the full changelog in the [effect repository](https://github.com/Effect-TS/effect/commits/main).

- [ability](https://github.com/nmnmcc/ability) - an authorization library that decides whether a principal may perform an action on a resource, with Schema-defined types and denials reported as Effect errors. By nmnmcc.

- [inkline-town](https://github.com/SandroMaglione/inkline-town) - a browser-based town-building simulation drawn in pale isometric line art. Built with Effect. By SandroMaglione.

- [effect-sql-pg-boss](https://github.com/wmaurer/effect-sql-pg-boss) - bring the pg-boss Postgres job queue to Effect, sending jobs within `@effect/sql-pg` transactions so they commit or roll back with your own rows. By wmaurer.

- [skill-guard](https://github.com/NoksLabs/skill-guard) - a trust gate that scans agent skill files, records approval of their exact content, and blocks unapproved or changed skills from loading in Claude Code, Codex, OpenCode, and Pi. Built on Effect 4 and `effect/cli`. By NoksLabs.

- [alchemy-unifi](https://github.com/HamishWHC/alchemy-unifi/tree/main/packages/network) - an Alchemy provider to define your UniFi networks, Wi-Fi, and zone-based firewall as code. By HamishWHC.

- [microfw](https://github.com/Trebh/microfw) - a small TypeScript framework implementing the SAM (State–Action–Model) pattern on Effect 4, using Layers to decide what runs in the browser and what runs on the server. By Trebh.

- [Effect Kit](https://effectkit.dev/) - open-source packages (Redis, Email, and Storage coming soon) that expose your infrastructure as Effect services with swappable Layers and typed errors.

- [effect-atom-tanstack-router](https://github.com/carloitaben/effect-atom-tanstack-router) - connect TanStack Router SSR hydration to Effect Atom for React and Solid, with Devtools included. By carloitaben.

- [herdr-web](https://github.com/DanielFGray/herdr-web) - a browser view of your herdr terminals, spaces, tabs, and panes, served by a Bun bridge that shares its API with the page as Effect RPC over a WebSocket. By DanielFGray.

- [check](https://github.com/sshkeda/check) - a strict TypeScript linter for Bun projects that steers code toward Effect, flagging async functions and global `fetch` in favor of `HttpClient` and typed errors. By sshkeda.
