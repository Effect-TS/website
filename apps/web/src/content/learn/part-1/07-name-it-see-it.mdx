The malformed rule fails, as it should. The failure in the terminal says what
went wrong, a `SchemaError` at `["op"]`, but not which part of the program it
came from. With one function you can guess. A real program has dozens of
steps. By the end of this lesson the same failure names the step it happened
in.

In this lesson you will:

- give an Effect function a name with `Effect.fn`
- learn what a span is
- find the name in a failure

## 2. Read the name in the failure

Look at the malformed rule's failure in the terminal. Under the
`SchemaError` there is now a line that starts with `at evaluate (`. That is
the name you passed to `Effect.fn`. The line after it,
`at evaluate (definition)`, points at where you declared the function.

Every call to `evaluate` now runs inside a **span** named `evaluate`. A span
is a record of one piece of work: its name, when it started, how long it
took, and whether it succeeded. When an Effect fails inside a span, the
failure that `runMain` prints names the span.

You do not see spans drawn as a timeline yet. That needs a trace viewer,
which you connect in
[Exporting traces with OtlpTracer](/learn/part-2/16-the-picture-you-already-know).

## Try it

The failure says it happened inside `evaluate`, but `evaluate` does several
things. Name the decode as well.

1. Turn `decodeRule` into a function made with `Effect.fn("decodeRule")`
   that takes the JSON string and decodes it.
2. Run the file and read the failure. It names both steps: `at decodeRule`
   first, then `at evaluate` under it. The decode failed, and it was running
   inside `evaluate`.

## What you learned

- `Effect.fn("name")` defines a function whose every call runs inside a span
  with that name.
- A span records one piece of work: its name, its start, its duration and
  its result.
- When a call fails, the failure lists the spans it was in, as
  `at evaluate (...)`.
- Spans cost a little time, and once exported, some traffic. Name the steps
  whose boundaries you want to see, not every helper. `matches` stays a plain
  function.
- The names you choose now are the names you read in the trace viewer in
  [Exporting traces with OtlpTracer](/learn/part-2/16-the-picture-you-already-know).
