Welcome back to This Week in Effect, your weekly update of the latest developments in the Effect community and ecosystem.

Effect is the TypeScript library for the AI era, helping developers build complex, synchronous, and asynchronous programs. One key feature that sets Effect apart is how it leverages structured concurrency to provide features such as async cancellation and safe resource management, making it easier to build robust, scalable, and efficient programs.

### Effect v4 updates.

Another busy week on `main`, with new modules landing alongside a steady stream of fixes across the platform packages. Here are the most notable changes.

- **Additions**: Added a GraphQL client and generator, a streaming tar codec in `effect/encoding`, `Schema.toCodecGoJson`, Semantic Versioning types with range support, and custom annotation imports for JSON Schema. Also added `Path.resolveWithin` for root-contained path resolution, `Host` helpers (`toFullyQualified`, `toRelative`, `parseHostsFile`), `NetAddress.loopbackAddresses`, `fromInput` functions for the net data types, and `CliOutput.displayWidth`.

<Tweet id="2109012416998826289" />

- **Cluster & workflow**: Added a `detached` option for discarded workflow executions. Failure-suspended workflows now stay parked until resumed or interrupted, suspended callers wake up when their workflow completes, and losing `DurableDeferred.raceAll` waits are released once the race settles. On the cluster side, shards are now handed off one at a time on shutdown, lease-based SQL shard lock renewal was restored, and a new annotation lets cluster RPCs be interrupted on termination. Also fixed the shards gauge after shard release.

- **RPC, HTTP & platform**: RPC gained an `onPingTimeout` option, and premature socket ping timeouts and connection defects that failed synchronously started requests were fixed. Added WebSocket handshake headers alongside subprotocols and `servername` support in client TLS upgrades. Fixed `HttpRouter` prefixes with path params breaking `request.url`, absolute HTTP URLs in opaque-origin documents, a UTF-8 BOM breaking JSON in Node HTTP text, `NodeStream` hangs on premature closure, and several child process edge cases.

- **SQL & persistence**: Exposed TCP keepalive settings in `sql-pg` and fixed released connection pins reaching the next borrower and inferred empty array binding. Fixed connection starvation in PGlite, the MSSQL error listener, the ClickHouse migrator ledger, Redis `PersistedQueue` data loss on lone-surrogate payloads and fractional Redis fixed-window rate limits. Event log replication, remote SQL journal conflicts and persistence expiry checks for reused reads were also fixed.

- **AI**: Fixed OpenAI Responses streams not ending at `data: [DONE]`, web search actions without patterns, service tier and provider-nested error metadata, and reasoning replay alongside tool calls in `openai-compat`. Invalid and undeclared tool calls are now returned when validation is deferred, Anthropic replies from a fallback model now decode correctly, and the Cloudflare provider can send decision images to Clef.

- **Observability**: Fixed several OTLP export issues: histogram overflow buckets, integers outside the int64 range, `NaN` and `Infinity` values, and batches dropped when a span has a 64-bit B3 trace id. The active span is now recorded on OpenTelemetry log records, and the DevTools client reconnects after socket failures.

- **Core & Schema fixes**: Fixed `Duration` conversions and `Duration.times` for very large or non-integer inputs, `Effect.cached*` under synchronous re-entrancy, `Stream.timeout` ending while the next chunk is pending, and atom rebuild loops from late dependency reads. `Match` now keeps the unmatched tail in array prefix patterns and rejects unknown keys in object patterns, `Array.match` exposes `NonEmptyArray` for mutable arrays, and `Schema.Enum` preserves literal member inference. Schema also rejects duplicate tagged union discriminants and merges colliding bounds in JSON Schema export instead of emitting `allOf`.

You can follow the full changelog in the [effect repository](https://github.com/Effect-TS/effect/commits/main).

To catch up on more updates, check out [Effect v4 Updates](https://www.effect.website/blog?category=effect-v4-updates), starting from the recently published [Effect v4 RC: September 2026 Updates](https://effect.website/blog/effect-v4-rc-september-recap).
