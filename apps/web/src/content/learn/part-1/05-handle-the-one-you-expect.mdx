The taxi stops the whole program. A missing amount is normal, not a
disaster. The alert does not apply to that event, so reflex should log that
it skipped the event and move on to the next one.

By the end of this lesson the program checks two events with the same code.
The laptop gets its alert, the taxi gets a skip line, and the program
finishes normally.

In this lesson you will:

- put the steps in a function that returns an Effect, so you can reuse them
- handle one error by its tag with `Effect.catchTag`
- attach a step to an Effect with `.pipe`
- watch the error leave the error type

## 2. Handle the error

`Effect.catchTag` handles exactly one error, picked out by its tag. Its
handler receives the typed error and returns the Effect to run instead.
Every other error passes through untouched.

Attach it to `evaluate` with `.pipe`, after the `Effect.gen(...)` block:

Every Effect has a `.pipe` method. `effect.pipe(f)` is the same as
`f(effect)`, and `effect.pipe(f, g)` is the same as `g(f(effect))`. It lets
you add steps after an Effect and read them left to right.

Run the file. The terminal prints a log line with the message
`expense 1200 over 500`, then one with `skip: missing field amount`, and the
program finishes normally.

## 3. Read the error type

Hover `evaluate`. Its return type is `Effect<string | void, never, never>`.

Before you added `catchTag`, the return type was
`Effect<string, MissingField, never>`. `MissingField` has left the error
type because it is handled, and nothing else can fail, so the error type is
`never`. The success type gained `void`, because the skip branch logs a line
and gives back nothing.

## Try it

Remove the `.pipe(Effect.catchTag(...))` from `evaluate` and hover `evaluate`
again. The error type is `MissingField`. Put the `catchTag` back and hover
once more. The error type is `never`.

## What you learned

- A function that returns an Effect runs the same steps on different inputs.
- `Effect.catchTag("Tag", handler)` handles one error by its tag and removes
  it from the error type.
- `.pipe` attaches steps to an Effect, read left to right.
- Every error is a decision: handle it here, or leave it in the type for the
  caller.
- A rule that is itself broken is a different kind of error. The next lesson,
  [Validating JSON with Schema](/learn/part-1/06-untrusted-json), lets it
  stop the program.
